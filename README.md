# ProofGuard
DTP・印刷物の誤字脱字から、Instagram・X(Twitter)のキャプションまで、AIが瞬時に校正。テキストを貼り付けるか、画像をアップロードするだけで、誤字・表記ゆれ・文字数オーバーなどを自動でチェックします。
From typos and missing characters in DTP and printed materials to captions on Instagram and X (Twitter), AI proofreads them instantly. Simply paste your text or upload an image, and it automatically checks for typos, inconsistent terminology, and character count violations.
